# 출시 기준 정책과 구현 확인 사항

사용자 지시에 따라 이용자 문서는 현재 개발 상태가 아닌 출시 구현 계획을 기준으로 작성한다. 아래는 이용자 페이지에 노출하지 않는 개발·운영 요구사항이다. 정책 문구 변경으로 기능이 구현된 것으로 간주하지 않는다.

## 문서에 반영한 출시 요구사항
- 계정 관리의 탈퇴·연동 해제 및 본인 확인 후 문의 처리
- 탈퇴 시 회원·연동 계정·게임 스냅샷·점수·공유 덱·투표·뱃지 삭제. 연동 해제 시 해당 연결·게임 정보·점수 삭제
- 개인별 비교 표본도 삭제/재집계. 비식별 집계만 유지
- 접속·오류 로그 최대 30일, 백업 최대 30일, 처리 완료 문의 최대 1년 보관: 이번 문서 작성에서 정한 구현 목표이며 현재 자동화 완료 사실이 아님
- DB와 외부 문의 폼의 삭제 절차, 백업 복원 시 삭제 재적용, 로컬 저장소 정리
- 커뮤니티 공개 범위·작성자 삭제·뱃지 전시 해제
- 로그인/개인정보 처리/외부 계산 전송에 필요한 고지·동의 흐름

## 운영 값 확정
- 개인정보처리방침 적용일: 출시 시 확정. 현재 페이지 날짜는 최종 개정일
- Firebase·Netlify 실제 계약 주체·리전·처리 국가 및 백업 위치
- Google·Netlify·DILDORO의 위탁/제공 구분과 국외 이전 세부사항(받는 자, 국가, 연락처, 시점·방법, 항목, 목적, 보유기간, 거부 방법)을 실제 계약 기준으로 확인하여 이전 고지에 기입
- 운영자 표시와 유효한 개인정보 문의 창구 확인. 원본 문의 링크는 네이버 폼임

실배포 이전 이 목록과 구현을 대조한다. 원본 MK1 Firebase 운영을 변경하지 않는다.
