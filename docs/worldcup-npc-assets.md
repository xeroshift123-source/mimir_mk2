# 월드컵 NPC 이미지

2026-11-16 사용자가 public/assets/images/npc에 추가한 WebP 이미지 39개를 이상형 월드컵의 NPC 참가자 전용으로 사용한다. 출처는 사용자 제공 파일이며 외부 원출처 정보는 제공되지 않았다. src/data/worldcup-npcs.json에서 참가자 ID·표시 이름·경로를 관리한다. 표시 이름은 한국어로 관리한다. 참가자 ID와 이미지 파일명은 저장 대진 호환성을 위해 유지한다. 실제 니케 카탈로그·덱빌더·스코어에는 추가하지 않는다. NPC 우승은 결과 이미지 저장·복사를 지원하며 기존 니케용 뱃지 API에 NPC를 전달하지 않는다.
